sleepwalk

Shut your MacBook. Claude keeps working.

A Claude Code mod for the desktop app on macOS. One switch keeps a session running with the lid shut, on battery or on the charger, and turns sleep back on when the work ends.

Install

One click opens the Claude Code app with the install request typed in. Press Return and Claude installs it.

Open in the Claude Code app →

Or paste this into Terminal and press Return:

claude plugin install sleepwalk --marketplace adamalshoomary/sleepwalk

Then start a new session in the desktop app.

  • Claude Code desktop app
  • macOS
  • Your Mac password

While it is on, the screen does not lock, so anyone who opens the lid finds the Mac unlocked. Keep a shut Mac on a hard surface, never in a bag or on a bed.

Other ways to install

In the desktop app: click + next to the prompt box, then Plugins, then Add marketplace. Type adamalshoomary/sleepwalk, then click Add plugin.

In a terminal session of Claude Code:

/plugin install sleepwalk --marketplace adamalshoomary/sleepwalk

Then turn it on

Click Keep working with the lid closed in the band above the prompt, or type /lid on. Type your Mac password, wait for sleepwalking in the footer, and shut the lid.

Before you shut the lidSwitch the session to Auto or Bypass permissions, or answer prompts from your phone with Remote Control.
When it endsSleep comes back on 2 minutes after the work ends, after 2 hours, at 25% battery or when the Mac gets hot.
Nothing left behindNo helper stays installed. If the lid is shut when it ends, the Mac goes to sleep straight away.
